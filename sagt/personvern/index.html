Sagt for Mac

Personvernerklæring

Kort fortalt: Sagt samler ikke inn data om deg. Lyden transkriberes på din egen Mac og forlater aldri maskinen.

Ingen datainnsamling

Sagt har ingen analyse, sporing, brukerkonto eller reklame, og inneholder ingen tredjeparts-SDK-er for slike formål. Utvikleren mottar ingen data fra appen.

Transkribering skjer lokalt

Sagt gjør om lydfiler til norsk tekst med talegjenkjenningsmodellen Whisper, som kjører på Macen din via WhisperKit og Core ML. Lyden sendes ikke til noen server.

Titler, sammendrag og «Spør prosjektet»

Disse funksjonene bruker Apples innebygde språkmodell (Foundation Models, macOS 26 eller nyere), som kjører på enheten. Teksten din sendes ikke til utvikleren eller andre tjenester.

Nettverkstilkobling

Appens eneste nettforbindelse er nedlastingen av språkmodellen (Whisper large-v3) og tilhørende tokenizer-filer fra Hugging Face, første gang du trykker «Last ned». Ingen opptak, tekster eller andre data fra appen sendes med. Som ved enhver nedlasting kan Hugging Face se vanlig teknisk informasjon, som IP-adressen din. Hugging Face har sin egen personvernerklæring. Etter nedlastingen fungerer Sagt uten nett.

Lagring og tilgang til filer

  • Opptak, transkripsjoner, prosjekter og søkeindeksen lagres lokalt i biblioteksmappen du selv har valgt. Du kan slette dem når som helst.
  • Sagt kjører i Apples App Sandbox og leser bare filer du selv drar inn i appen eller velger.

Kjøp

Sagt har ingen kjøp i appen og ingen abonnement.

Endringer

Hvis denne personvernerklæringen endres, publiseres den nye versjonen på denne siden med ny dato.
